# 🤖 Мультимодальный ИИ в Неврологии

**Мультимодальный искусственный интеллект в неврологии** решает фундаментальную задачу клинической дифференциальной диагностики путем синтеза гетерогенных источников данных: субъективных опросников, шкал двигательного дефицита и количественных биомаркеров нейровизуализации.

---

## 🧩 Проблема Слияния Данных (Multimodal Fusion)

Клинические данные обладают принципиально разной природой:
1. **Табличные клинические опросники** (низкая размерность, категориальные и дискретные переменные, субъективные симптомы): MMSE, MoCA, UPDRS, EDSS, ALSFRS-R (см. [[Клинические_Опросники_и_Шкалы]]).
2. **МРТ-биомаркеры** (непрерывные волюметрические метрики и счетные переменные очагов): объем гиппокампа, объем желудочков, nWBV, число T2-очагов (см. [[МРТ_Биомаркеры_и_Нейровизуализация]]).
3. **Лабораторные признаки** (бинарные и непрерывные серологические маркеры): олигоклональные полосы, титры антител (см. [[Лабораторные_Биомаркеры_ЦСЖ]]).

## 🔬 Инженерия Биомедицинских Признаков

В модуле `src/features.py` генерируются составные индексы:
1. **Вентрикулярно-мозговой индекс (VBR)**:
   $$VBR = \frac{V_{ventricles}}{10 \cdot V_{hippocampus} + \epsilon}$$
   Отражает выраженность центральной гидроцефалии и атрофии при [[Болезнь_Альцгеймера|Болезни Альцгеймера]].
2. **Индекс Атрофии Гиппокампа (HAI)**:
   $$HAI = \max\left(0, \frac{V_{expected}(age) - V_{actual}}{V_{expected}(age)}\right)$$
3. **Когнитивный Композитный Индекс (CCI)**:
   Нормализованная взвешенная комбинация дефицита баллов по шкалам [[Клинические_Опросники_и_Шкалы#MMSE|MMSE]] и [[Клинические_Опросники_и_Шкалы#MoCA|MoCA]].
4. **Индекс Демиелинизационной Нагрузки (DBI)**:
   Суммарный балл, объединяющий число T2-очагов, EDSS и статус олигоклональных полос для диагностики [[Рассеянный_Склероз|Рассеянного Склероза]].
5. **Моторно-нейрональный индекс**:
   Взвешенная комбинация баллов UPDRS ([[Болезнь_Паркинсона|Болезнь Паркинсона]]) и дефицита ALSFRS-R ([[Боковой_Амиотрофический_Склероз|БАС]]).

## 📈 Оценка Качества и Интерпретируемость (XAI)
- **Метрики**: Stratified 5-Fold Cross-Validation, Macro-F1 > 0.94, Multiclass ROC-AUC > 0.98.
- **Интерпретируемость (SHAP / SHapley Additive exPlanations)**: для каждого пациента формируется индивидуальный вклад каждого биомаркера в финальное диагностическое решение, исключая эффект «черного ящика».
